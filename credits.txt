# UI sound pack — credits

Every file in `v3/assets/audio/ui/` is built by `v3/design/tools/build_ui_audio.py` from **real recordings only** (no oscillators): layered, varispeeded, filtered, with a small convolution plate made of filtered noise. Delivered as `.ogg` (oggenc -q 6) + `.mp3` (192k), 44.1 kHz stereo, each normalised to max-momentary −16 LUFS (400 ms K-weighted) and capped at −1.5 dBFS peak; the per-sound mix level is `gain` in `index.json` (bus `ui`).

## Licences in use

* **CC0 1.0 / Public domain** — no attribution required (credited anyway).
* **CC BY 4.0** — inherited through reused NEXT bank layers; attribution below is required in the game credits.

## What is what
- Guns (real recordings, 2026-09-25 rebuild): single shots are cut out of the Free Firearm Sound Library by
  `next/blender/enemies/enshots.py` (onset detection, each shot keeps its own natural tail until the next shot).
  - `en_pistol_shot_1..6` — close: PPQ ×3, 1911 ×2, Bersa ×1; each = the near recording + the same gun's mid-distance
    recording as body (−6 dB) + diffuse street reflections (28 decaying taps, low-passed, −8 dB), light limiting,
    peak −1.5 dBFS, index gain 1.5. `en_pistol_shot_far_1..5` — the mid recordings, low-passed (air absorption) with a
    longer reflection tail, peak −4 dBFS.
  - `en_rifle_shot_1..6` — close: AK-47 ×4, SKS ×2 (same 7.62x39 cartridge), built the same way, peak −1 dBFS.
    `en_rifle_shot_far_1..4` — AK/SKS mid recordings, distant treatment.
  - Variant sets: `en_pistol_shot`, `en_pistol_shot_far`, `en_rifle_shot`, `en_rifle_shot_far`. Gunshots are
    peak-normalised (not loudnorm'd, which would flatten the transient).
  - Reloads: the library has gunshots only (no handling), so `en_pistol_mag_out/in`, `en_rifle_mag_out/in`,
    `en_rpg_*` stay Kenney metal clicks/latches and `en_pistol_slide` / `en_rifle_bolt` stay Jurek's pump recording.
  - `en_shell_drop_1..3`, `en_rpg_launch/flight`, `en_explosion`, `en_bullet_flyby`, `en_impact_concrete/metal` unchanged.
- Melee: `en_swish_1..4`, `en_knife_swish/hit`, `en_bat_swish/hit`, `en_punch_hit_1..3`, `en_hit_body`, `en_ground_pound`.
- Body: `en_step_1..6`, `en_cloth_1..4`, `en_body_fall`, `en_web_creak`.
- Voice (rebuilt 2026-09-26 from real non-verbal recordings; the old countdown-based files stay in
  `next/blender/enemies/_cache/_rejected_voice/`). Every take was transcribed with whisper (ggml-small, en) and anything

# Spider-Man (Iron Spider) sound bank -- credits

Every `sp_*` sound in this folder is built by `build_audio.py` (same folder) from the real recordings
listed below: cut sample-accurately, varispeeded (tape-style resampling, incl. pitch glides), reversed,
enveloped, EQ'd (incl. a time-varying resonant band swept through recorded noise), compressed and
layered. No oscillator synthesis anywhere. `python3 build_audio.py --fetch && python3 build_audio.py`
downloads the sources (re-checking each licence on the source site) and rebuilds the whole bank.

## Licences in use

* **CC0 1.0** (Freesound, OpenGameArt, Kenney) -- no attribution required, credited anyway.
* **Public domain** -- the PDSounds.org collection mirrored on Wikimedia Commons (`PD-author`). Strictly
  more permissive than CC0 (no rights reserved at all); listed separately so it is visible.
* **CC BY 4.0** (Gravity Sound library on Commons) and **CC BY 3.0** (reemax, OpenGameArt) -- attribution
  required, given below.

No CC BY-SA, no NC, no rips. Freesound material is used only where the sound is CC0 (the HQ preview mp3).

## Loudness

* Sounds >= 0.4 s: gain set from ffmpeg `loudnorm` (EBU R128) measurement to **-16 LUFS integrated**,
  applied as a single linear gain (no dynamic processing), capped so the true peak stays <= -2 dBTP.
* One-shots < 0.4 s: integrated loudness is not meaningful that short, so the gain is set from the
  loudest 100 ms K-weighted window (target -11.0 LUFS on that window, which is where the -16 LUFS-I
  items land), with the same true-peak cap.
* `gain` in index.json balances ids against each other (sp_thwip_1 = 1.0 reference).
* Loops: use the `.ogg` in engine (MP3 encoders add padding at the start, which breaks gapless looping).
